Paper Size Reference サポート

Paper Size Reference は、同人誌・ZINE・自費出版の冊子づくりで、印刷所ごとの式から背幅と表紙の寸法を出すアプリです。

使い方

  1. 「本の設計」で印刷所を選び、綴じ方・右綴じ/左綴じ・判型・ページ数・本文と表紙の紙を選ぶと、背幅・表紙の全体寸法・塗り足し・安全域・ピクセル数が出ます。
  2. 「ほかの印刷所だと」で、同じ本を収録したすべての印刷所で刷ったときの背幅を比べられます。
  3. 「道具」から、本文 PDF のチェック・背文字の大きさ・紙の厚さの逆算・立体の見本を開けます。
  4. Pro では、表紙テンプレート（透明な PNG・原寸の PDF）と新刊告知の画像を書き出せます。

よくある質問

Q. 無料版でどこまで使えますか？

A. 背幅・表紙の寸法・ピクセル数・警告・印刷所の比較・本文 PDF のチェック・背文字の大きさ・紙の厚さの逆算・立体の見本は、すべて無料でご利用いただけます。

Q. Pro（買い切り）では何が増えますか？

A. 表紙テンプレートの書き出し（透明な PNG・原寸の PDF）、新刊告知の画像の書き出し、本の保存、中綴じのページ割り表が使えます。自動更新はありません。

Q. 背幅は正確ですか？

A. 各印刷所・出版サービスの公開資料から式・紙の厚さ・丸め方を取り、計算例を公開している会社はその例と一致することを確かめています。出典と確認日はアプリ内に表示しています。紙の在庫や式は変わることがあるため、入稿前に印刷所の最新の案内もご確認ください。本アプリは各社の公式アプリではなく、各社とは関係ありません。

Q. 表紙の画像や PDF はどこかへ送られますか？

A. いいえ。選んだ画像と PDF は端末の中で読むだけで、どこにも送りません。

Q. インターネット接続は必要ですか？

A. いいえ。すべて端末内で動作し、オフラインでも利用できます（購入と復元のときだけ App Store に接続します）。

Paper Size Reference calculates the spine width and cover size of doujinshi, zines and self-published books with each printer's published formula, exports cover templates, checks interior PDFs and shows a 3D mockup.

Is it free?
